# SlumsMS brand art

Made for the owner (2026-10-26); the source art for the client and launcher. Transparent PNGs.

- `slumsms-wordmark.png` (2172x724): the graffiti "SLUMS MS" logo. The login screen uses it
  (`tools/login-logo/set_logo.py` writes it into `Data/Map/Obj/login.img`, `Title/logo/0`).
- `slumsms-emblem.png` (1254x1254): the duct-taped leaf badge, for app and launcher icons.
- `slumsms-mascot-bucket.png`, `slumsms-mascot-girl.png`: mascots for the launcher, site and loading art.
